Build a **fully functional, modern, responsive web application called “SmartAgri Map”**.

## PROJECT IDEA

SmartAgri Map is a map-based Smart Agriculture platform where farmers can report agricultural problems such as:

* 🌱 Crop Disease
* 🐛 Pest Attack
* 💧 Water Shortage
* 🌍 Soil Problems
* 🌾 Crop Damage

Farmers can report problems with their location and image. Agriculture officers can view the reports on an interactive map, update their status, and resolve problems.

The main flow is:

**Report Problem → Get Location → Display on Map → Officer Reviews → Update Status → Resolve Problem**
